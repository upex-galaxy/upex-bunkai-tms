Create the user personas for the PRD, as a product manager and UX researcher would.

**Input:**

- Executive Summary: [use .context/PRD/executive-summary.md]
- Business Model: [use .context/business/business-model.md]

**Generate file: user-personas.md**

Create 2-3 detailed personas.

**For each persona:**

1. **Fictional name + photo description**
   - A name that represents the profile
   - A description for generating an AI image (age, appearance, context)

2. **Demographics**
   - Age
   - Occupation
   - Location (country/city)
   - Education level

3. **Goals** (what do they want to achieve?)
   - 3-4 main goals
   - Tied to the problem the product solves

4. **Pain Points** (current frustrations)
   - 3-4 specific pain points
   - How each one affects their day

5. **Tech Savviness** (technology adoption level)
   - Early adopter / Mainstream / Late adopter
   - Devices and apps they use regularly

6. **Representative quote**
   - One sentence that captures their frustration or need
   - In quotation marks, first person

**Format:** structured Markdown, ready to copy into `.context/PRD/user-personas.md`

**Constraints:**

- Realistic personas, based on the target audience
- Different profiles (not all alike)
- Specific, not generic
