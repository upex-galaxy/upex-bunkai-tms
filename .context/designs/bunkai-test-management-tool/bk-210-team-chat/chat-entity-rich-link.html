03 · Card anatomy — spec

One row: type icon, id-chip, title, status chip. Project as the subtle second line. Verdict and status always pair color with an icon and a text label — never color alone.

RUN-451 Checkout smoke suite Pass Kaiju Web·staging·45/45 steps
  • 1Type icon — 14px Lucide line icon in --fg-2 tier: terminal for Run, file-check for ATC, flask for Test.
  • 2Id-chip — the same JetBrains Mono chip used for inline ATC-118 references in running text. One idiom everywhere.
  • 3Title — entity name, single line, ellipsized. Cards cap at 316px inside the 380px panel.
  • 4Status chip — signal palette tint + icon + label. Pass/fail for Run verdicts; workflow states for ATC.
  • 5Second line — project, then environment (mono) and step counts for runs; layer for ATCs. Secondary text tier.
  • 6Inert variants — dashed border, grey tint, italic title, no shadow, no hover, no pointer. Restricted shows no id, title, or project; deleted keeps the id already visible in the message.
