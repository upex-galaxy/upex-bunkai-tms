# BK-441 — Workflow

> Jira field: `customfield_10104` · [View in Jira](https://jira.upexgalaxy.com/browse/BK-441)

A QA Engineer narrowing the ATC Library adds a Project, Module, layer, or User Story / Acceptance Criterion filter, and the list narrows further, combining every active facet together with any active search term already typed. Selecting a Project narrows the Module filter's own options down to that Project's Modules.

When they want a clean slate, they trigger "Clear all" and the list returns to its full unfiltered state in one gesture — search term and every filter cleared together, with the URL reflecting the change under the same replace semantics search already established.
