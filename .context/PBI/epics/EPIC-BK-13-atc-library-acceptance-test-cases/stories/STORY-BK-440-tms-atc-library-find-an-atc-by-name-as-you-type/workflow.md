# BK-440 — Workflow

> Jira field: `customfield_10104` · [View in Jira](https://jira.upexgalaxy.com/browse/BK-440)

A QA Engineer already viewing the ATC Library types a few characters, or presses "/" to jump straight to the search field, to narrow the list by name; the list narrows incrementally as they type, with no need to submit a search.

If they want a clean slate, Esc clears the term while the field is focused and the list returns to its unfiltered state. If they open a row and come back with Back, their search term is still there — restored from the URL.

If nothing matches what they typed, the screen shows the same explicit "nothing found" state used for an empty workspace, not an error.
