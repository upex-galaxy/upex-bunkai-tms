# BK-443 — Workflow

> Jira field: `customfield_10104` · [View in Jira](https://jira.upexgalaxy.com/browse/BK-443)

1. Elena, a Senior QA Engineer, narrows the Bugs list to one module, two severities and the current sprint's date range — the combination she works from most mornings.
2. Today, following a link out to an ATC and coming back leaves her rebuilding it from scratch. Instead she saves the current view and names it, for example "Checkout blockers, this sprint".
3. The view appears in the saved-view list for that surface. It is hers alone; nobody else in the workspace sees it.
4. Later she opens it in one click and the list comes back exactly as she left it: same module, same severities, same dates. The address reflects those filters too, so the same narrowed list is reproducible by link for anyone who could already see that data.
5. When the sprint moves on she opens the view, adjusts the date range, and updates the saved view in place rather than accumulating near-duplicates.
6. She renames one whose label stopped describing it, and deletes another she no longer uses. Deleting it leaves the list she is looking at exactly as it was.
7. If a module inside a saved view was archived in the meantime, opening it still works: the filters that still apply are applied, and Bunkai tells her which part no longer does instead of quietly dropping the view.
8. On a surface where she has saved nothing yet, she sees a plain "no saved views yet" state offering to save the one she is on.
