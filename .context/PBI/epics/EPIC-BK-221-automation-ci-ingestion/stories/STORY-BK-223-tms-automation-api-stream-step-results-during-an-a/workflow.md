# BK-223 — Workflow

> Jira field: `customfield_10104` · [View in Jira](https://jira.upexgalaxy.com/browse/BK-223)

The nightly pipeline hands Karim a Test to execute. He starts a run in Bunkai and reports each step as it completes. Elena, curious whether the nightly is healthy, opens the run and watches steps turn green one by one — until step 3 turns red. Karim finishes the run with verdict failed, and it lands in the project runs view as a normal finished run. Last week, when the runner crashed mid-run, the run was aborted with the reason "runner crashed" and its two reported steps preserved — an honest partial record instead of a silent gap.
