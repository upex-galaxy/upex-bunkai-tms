## Overview

## User story

As Sara Iglesias, a Full-Stack Developer, I want to edit and delete my own chat messages, so that I can fix typos and retract mistakes without polluting the channel with corrections.

## Context

Real conversations include wrong URLs, typos, and messages sent to the wrong channel. This story lets a member edit a recently sent message (with a visible edited indicator) and delete their own messages (leaving a tombstone so the conversation flow stays honest). Ownership is the rule — you touch only your own messages — with one role-based exception: admins and owners can moderate by deleting any message. It builds on the message primitives from the workspace channel story and activates with it.
